# ADR-001: Modular Monolith First

## Summary

Architecture Decision Record accepting the modular monolith as the initial deployment style. Chosen for faster iteration, lower operational complexity, and easier evolution toward microservices when needed.

## Key Claims

- **Status**: Accepted
- **Decision**: Use modular monolith architecture
- **Reasons**: Faster iteration, lower complexity, easier evolution
