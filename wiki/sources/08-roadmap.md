# Roadmap

## Summary

Three-phase roadmap. Phase 1 is the MVP (Agent/Tool CRUD, single-agent execution, Redis memory). Phase 2 adds agent teams, workflow engine, and multi-agent handoff. Phase 3 introduces multi-tenancy, observability, and Kubernetes.

## Key Claims

- **Phase 1 MVP**: Agent CRUD, Tool CRUD, single-agent execution, execution logs, Redis memory
- **Phase 2**: Agent teams, Workflow engine, Multi-agent handoff
- **Phase 3**: Multi-tenancy, Observability, Kubernetes
- No trigger criteria defined for when Phase 2 or 3 begins
